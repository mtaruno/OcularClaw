System Architecture

Proactive Conversational AI Agent for Smart Glasses

High-Level System Overview

Three-layer architecture: capture input, process through LLM pipeline, deliver recommendations

Input Layer

  • Microphone (smart glasses)
  • Web Speech API / Whisper
  • Rolling transcript buffer
  • Speaker diarization (P1/P2)

Processing Layer

  • Task A: Goal Inference
  • Task B: Intervention Decision
  • Task C: Recommendation Gen
  • LLM (GPT-4.1-mini)

Output Layer

  • Visual HUD overlay
  • 2 recommendations (say/know)
  • Urgency + proactive score
  • Session log (JSON)

Core Pipeline: A → B → C

Every 15 seconds, the agent runs three tasks in sequence on the latest transcript

Rolling Transcript Buffer (last ~120s of conversation)

Task A — Goal Inference

"What is the wearer trying to accomplish?"

wearer_goal goal_type goal_confidence

Task B — Intervention Decision

"Should I speak up right now?"

action (none / recommend) proactive_score (1-5) signal_type reason
action = "recommend"?
No → Silent
No intervention. Wait for next check.
Yes → Generate

Task C — Recommendation

"What should they say or know?"

recommendation_1 recommendation_2 rec_mode (say/know/both) urgency

3-Part Evaluation Framework

Triangulated evaluation: automated metrics + expert annotation + live participant study

Part 1: Automated Benchmark

Researcher only

  • 17 scenarios × 7 models
  • Task B precision / recall
  • Trigger timing delta
  • Proactive score RMSE
  • Goal inference accuracy
RQ1 RQ4 RQ5

Part 2: Expert Scorecard

Researcher + 1-2 labmates

  • Per-trigger quality annotation
  • 8 binary metrics (Tasks A/B/C)
  • Accept / edit / reject decisions
  • Inter-rater agreement (Cohen's κ)
RQ2 RQ4

Part 3: Live Role-Play

10 participants × 5 scenarios

  • Real-time agent interaction
  • Calibration gradient (score 4 → 1)
  • Post-session: 4 Likert + 3 free-text
  • Exit survey: frequency pref, best/worst
  • Helpfulness, timing, goal, adoption ratings
  • Qualitative thematic coding
RQ3 RQ5
