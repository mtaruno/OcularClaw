## Key Insights Summary

### 1. "Know" > "Say" (Recommendation Mode)
Marjorie consistently preferred **informational hints** over **verbatim scripts**. When the agent told her what to say word-for-word, she felt she was "not really thinking" and it "wouldn't feel natural." Shorter, directional suggestions ("specify exact deadline dates") were preferred over full sentences to recite.

### 2. Scenario-Dependent Utility
The agent's value varied dramatically by context:
- **S1 (Professional meeting):** Most natural fit. Proactive reminders (like follow-up actions) were genuinely helpful.
- **S2 (Persuasion):** Moderate. Good when acknowledging emotions, bad when repetitive.
- **S3 (Emotional support):** **Worst fit.** "Therapist tone" felt unnatural for friendship. Both parties would feel awkward.
- **S4 (Casual planning):** High potential if it could search/brainstorm, but conversation coaching was unwanted.

### 3. Tone Calibration Matters
The agent spoke with the same professional/clinical tone across all scenarios. In emotional contexts, this created a mismatch — "that's just not how you talk to your friends." The agent needs scenario-aware tone calibration.

### 4. Repetition is the Top Annoyance
Multiple triggers with the same advice was the primary negative. The agent needs deduplication logic — don't re-trigger on the same signal within a conversation.

### 5. Information Retrieval is the Missing Feature
For casual/planning scenarios, Marjorie wanted the agent to **search for relevant information** (restaurant availability, weather, event details) rather than coach her conversation. This represents a clear feature gap.

### 6. Cognitive Load Concern
Even when helpful, Marjorie worried about the cognitive load of reading recommendations while simultaneously conversing. This supports shorter, more concise recommendation formatting.

### 7. Timing Sensitivity
15-second check intervals sometimes produced stale recommendations when the conversation topic had already moved on. Faster checks or topic-change detection could help.

### 8. Goal Inference Was Consistently Accurate
Across all scenarios, Marjorie agreed the agent correctly understood what she was trying to accomplish — even when the recommendations themselves weren't helpful. Task A works; Tasks B and C need scenario-aware tuning.
